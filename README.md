# Brasfone — Motor de análise de conversas WhatsApp com IA

App multi-tenant para o Pipedrive Marketplace que liga o WhatsApp Business (Meta Cloud API) ao Pipedrive: analisa conversas com IA, extrai compromissos assumidos com clientes e cria automaticamente actividades no CRM.

A especificação completa do produto, arquitectura, stack e milestones está em [`CLAUDE.md`](./CLAUDE.md). Decisões de produto assumidas por omissão ficam registadas em [`DECISIONS.md`](./DECISIONS.md).

Este repositório está em fase de arranque (pré-M1) — ver `CLAUDE.md` para o plano de milestones.
